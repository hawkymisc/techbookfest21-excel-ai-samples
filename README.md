# 「面倒なExcel作業はAIにやらせよう」サンプルデータ

技術書典21で頒布する「面倒なExcel作業はAIにやらせよう」の本文で使うサンプルの Excel ファイルと、それを作るスクリプトです。

## 使い方

1. このページの「Code」→「Download ZIP」でダウンロードし、展開します。
2. 本文の指示に合わせて、`samples/` の中のファイルを作業用のフォルダにコピーしてから使います。元のファイルは残しておいてください。

`samples/answers/` には、本文の作業をしたあとの完成形（正解）が入っています。AI の作業結果と見比べるのに使います。

## 中身

データはすべて架空の会社「株式会社ミナセ流体工業」（製造業、従業員約420名）のものです。実在の会社・人物・取引とは関係ありません。期間は2024年10月〜2026年9月の24か月です。

| ファイル | 内容 |
|---|---|
| `samples/売上明細_2024年10月-2026年9月.xlsx` | 24か月分の売上明細（日付ごと、約7,000行） |
| `samples/部署名一覧_付番前.xlsx` | 書き方がばらばらな部署名の一覧（部署コードはまだない） |
| `samples/取引先リスト_手入力.xlsx` | 手入力で管理している取引先リスト（表記ゆれあり） |
| `samples/部署別売上予算_2025年度.xlsx` | 見た目を重視して作った予算表（結合セルあり） |
| `samples/代理店報告_2026年9月/` | 販売代理店20社から届いた2026年9月の販売報告（訂正版・再送を含む24ファイル） |
| `samples/月次営業報告書_テンプレート.xlsx` | 毎月の営業報告書のひな形 |
| `samples/部署別売上_2026年9月.xlsx` | 値・数式・書式の違いを見るための集計表 |
| `samples/生産実績ログ_2024年10月-2026年9月.xlsx` | 工場の生産実績ログ（約44万行、約20MB） |
| `samples/answers/` | 上の各ファイルで作業したあとの完成形 |

## サンプルを作り直す（エンジニア向け）

`tools/` のスクリプトで、同じ内容のファイルを作り直せます。乱数のシードを固定しているので、何度作っても中身は同じです。

必要なもの：Windows、Microsoft 365 の Excel デスクトップ版、[uv](https://docs.astral.sh/uv/)

```
uv sync
uv run python tools/make_sales.py
uv run python tools/make_production_log.py
```

ほかのファイルも `tools/make_*.py` で作ります。スクリプトは Excel を画面に出さずに動かし、保存したあとで作成者名などの個人情報をファイルから取り除きます。
